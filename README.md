# CareerPilot AI

AI-powered career readiness platform that analyzes a resume against a target job, identifies skill gaps, and generates an actionable career roadmap.

## MVP

- Resume PDF analysis
- Job description matching
- ATS / match score
- Matched and missing skills
- AI resume feedback
- Skill-gap analysis
- Personalized learning roadmap
- Interview question generation

## Structure

- `frontend/` — React + Vite application
- `backend/` — FastAPI application
